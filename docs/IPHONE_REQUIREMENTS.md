## 文件夹授权与来源切换

通过 iOS 系统目录选择器授权，保存手机私有书签，并在每次读取期间保持安全作用域有效。不能硬编码 Mac 的 Library／CloudDocs 路径，也不能复制 Mac 的书签、关联文件或设备标识到手机。

Mac 常用位置为 iCloud Drive 中的 `RadioBar/RadioBarSync`，旧位置也可能为根目录下的 `RadioBarSync`，用户还可选择自定义目录。手机应接受合法的 `RadioBarSync` 数据目录或其直接父目录；只按这两种明确边界检查，不递归搜索，不重复嵌套，不创建目录。候选有歧义时要求重新选择。

- 首次读取到完整合法且只有一个最新分支的库后，绑定其 `libraryID`；它标识配置库，不是 Apple 账户身份。
- 空目录、目录缺失、文件未下载、损坏、较新格式或未解决分支不能初始化手机配置库，也不能覆盖已有缓存。无缓存时显示等待有效配置。
- 更换文件夹先检查候选。不同配置库显示摘要并由用户确认切换；候选失败、取消或尚未准备好时保留旧来源和缓存，不静默混合两个库。
- 书签失效提供重新选择入口，不能退回猜测路径。系统明确报告授权／来源变化时保留缓存并提示检查来源；不能仅因某个账户查询值为空就认定 iCloud 已退出。
- 解除关联只停止后续读取，保留最后有效缓存和当前播放，不删除云端文件，不自动重新关联。清除缓存是另一个产品选择，不与解除关联捆绑。
- 未关联时保留现有 App 的默认资料行为，来源明确标为默认资料；不能将默认列表或旧缓存标成刚从 Mac 更新的配置。

新来源应在完整候选和私有缓存安全持久化后才生效。需要等待 Mac 首次发布时，可保存候选授权供重试，但不能提前替换当前有效来源。

## 与 Mac 兼容的读取协议

复用现有 Swift／Foundation 模型及校验，不另建 `latest.json`，不按修改时间选文件。共享目录只交换不可变完整快照，文件名为小写版本 UUID 加 `.json`，名称中的 UUID 必须等于内容的 `revisionID`。

| 快照字段 | 含义与约束 |
|---|---|
| `schemaVersion` | 当前为 1；无法理解的格式保留缓存并提示升级，不降级写回 |
| `libraryID` | 同一配置库的 UUID；不同库不自动合并 |
| `revisionID` | 本次发布的唯一 UUID；同 ID 不同内容属于无效历史 |
| `parentRevisionIDs` | 父版本 UUID 数组，可有多个父节点；决定后继和冲突关系 |
| `deviceID` | Mac 发布端标识；手机读取时不生成自己的发布设备 ID |
| `createdAt` | 仅用于展示；当前编码沿用 Swift JSONEncoder 默认 Date 表示，不自行改成 ISO 字符串 |
| `configuration.document` | 原始 `stations.json` 字节的 base64 编码，保留未知字段与原始值 |
| `configuration.preferences` | `orderIDs`、`visibilityOverrides`、可省略的 `defaultStation`；后者缺省为上次收听，`random` 表示随机，否则是电台 ID |

普通电台文档为 `schemaVersion: 1` 和 `stations` 数组。每项有 `id`、双语 `name`、`urls`，以及可选 `fullName`、`frequencyMHz`、`category`、`defaultVisible`；具体约束以共享校验器为准。文档最多 1 MiB／500 个普通台，单个同步快照最多 4 MiB，共享偏好条目等上限沿用模型，不另加更小的协议限制。

合法的普通台空数组仍会与两个代码内置台合并；它不同于没有读取到文件。显示选择和失效默认台沿用 `normalized()` 规则，至少保留一个显示台。不要把等待、错误或缺文件转换成一个成功的空配置。

读取步骤：

1. 在后台、有效目录授权内完成文件协调读取。非递归枚举专用目录，只读取符合命名的版本文件，拒绝链接、文件名身份不符和越界内容；其他文件不参与同步。
2. 识别下载元信息和 `.UUID.json.icloud` 占位。需要系统下载时由 iOS 适配层有节制请求，并等待完成；不能把占位正文当作快照，不能循环重试或新建替代文件。
3. 完整校验每个快照及版本图。一次扫描失败或被数量／时间／内存预算中断时，整次结果不能作为完整版本集提交；达到扫描预算不等于文件损坏。
4. 使用 `StationSyncReader.refresh` 判断更新。缺祖先／缺缓存版本等待；同一库多个分支交由 Mac 解决。只有完整、合法、单一且承接已缓存版本的后继才可接受；旧的文件提供商视图不能回退缓存。
5. 在 reader 的候选副本上计算变化，先原子持久化私有缓存及一致的来源信息，成功后再安装候选 reader，并一次性发布新列表。缓存写入失败保留原 reader、列表、偏好和播放。
6. `.current` 和重复通知不重写缓存、不重新创建播放器。冲突被 Mac 解决后，接受承接分支的新版本，手机不选择分支、不生成合并版本。

`StationSyncFiles` 同时包含读写工具，手机控制层只暴露读取能力；不调用 `publish`、`replace`、Mac 的同步规划器或本地发布状态保存流程。使用下载服务不等于获得向共享目录写配置的权限。

## 私有缓存与读取节奏

缓存放在 iPhone App 私有持久目录，不能仅存临时目录或可随时清理的缓存目录；不能写回 iCloud 同步目录。缓存应包含完整已验证快照及其配置库／版本关系，书签和本地状态与来源一致恢复，不把设备偏好整份复制到共享偏好中。

启动先验证并使用最近有效私有缓存，再检查云端。错误、下载等待、未解决冲突、旧目录视图、格式过新都保留有效缓存；App 被终止后重开仍可使用它。缓存损坏时保留原文件用于排查，不反复复制同一损坏文件，不能宣称恢复成功；先尝试验证上一份有效副本，再重新读取云端。两者均不可用时进入明确错误／等待状态。

建议私有缓存只保留当前有效快照与一份用于替换失败恢复的上一份副本，不按每次通知累积备份。替换临时文件由程序管理，中断恢复后清理已确认不再需要的自有临时文件。File Provider 可能另外缓存下载内容，这部分大小不能冒充 App 私有缓存大小，也不由手机删除共享历史来释放空间。

读取节奏沿用 Mac 的克制原则：启动、回到前台、有效目录变化通知和用户“重新读取”触发，连续通知合并。建议前台定时兜底为 10 分钟，离开前台停止该兜底；不承诺后台定时读取或即时到达，不为配置同步新增后台保活。

离线时保留可见列表，但收听直播仍可能失败。重新读取仅刷新配置，不启动音频会话。切换来源、解除关联、取消或退出页面后，旧异步任务不得发布结果或恢复旧关联；用来源与任务代次校验，取消不替代迟到结果检查。

## 页面与问题处理

沿用现有设置页中的“电台配置 / Station configuration”，不在正常播放首页常驻同步卡片。提供选择／更改文件夹、重新读取、最近检查、最后成功采用配置的时间、解除关联及问题排查。正常状态保持简短；区分“已检查”和“已采用更新”，不显示“已上传”或虚构对端收到状态。

| 状态 | 呈现与操作 | 配置行为 |
|---|---|---|
| 未关联 | 显示默认资料或已有本地来源，可选择文件夹 | 不自动授权或创建库 |
| 首次等待发布 | 等待 Mac 发布配置，可重新读取／重新选择 | 无有效云端配置不制造成功结果 |
| 正在读取 | 保留旧结果，禁用重复读取 | 不清空列表或重建页面 |
| 已有有效缓存 | 可查看来源、成功采用时间 | 断网仍显示缓存 |
| 权限失效／目录不可用 | 检查权限，重新选择 | 不退回猜测路径、不清空缓存 |
| 下载未完成／版本不齐 | 等待系统下载后重试 | 不当作删除 |
| 文件损坏／格式过新 | 脱敏原因、重试或更新 App | 保留缓存，不自动修复或降级 |
| 多个 Mac 分支／库不符 | 提示到 Mac 处理或明确选择新来源 | 手机不解决冲突、不回写 |
| 缓存无法写入 | 提示本机存储问题并允许重试 | 新配置不发布到界面 |
| 解除关联 | 停止读取，保留缓存 | 当前播放继续 |

诊断只在内存中保留最多 100 条事件／64 KiB，支持用户主动预览、复制和清除；可记录问题分类、阶段、数量和可信错误码，不包含路径、文件名、书签、账户／设备／配置库标识、电台 URL、token、请求头或配置正文，不自动上传。

新界面文案同步简体中文和英文，繁体沿用现有转换。检查三语、浅深色、大字号、VoiceOver 和滚动；按钮使用已实现的真实动作，不能把旧概念预览控件当成接入完成。

## 播放保护

始终由现有唯一 `PhoneRadio` 持有会话。配置读取层只提交有效列表和偏好投影，不能创建新播放器、启用音频会话、触发播放、解除输出安全锁或替代用户操作。

| Mac 配置变化 | 要保留的行为 |
|---|---|
| 排序或显示变化 | 更新选台和上一台／下一台的有效集合，不重连当前健康流 |
| 当前台隐藏或删除 | 从可选集合移除，保留正在播放的 Station 快照和健康连接；显示必要的隐藏／移除提示，不自动切台 |
| 名称或分类变化 | 可更新可见资料及 Now Playing 元数据，不重建音频连接 |
| 当前台地址变化 | 不为了配置刷新重建健康连接；新建连接使用新配置的细则见待确认项 |
| 默认模式改变 | 影响后续有效起始选择，不改变当前播放意图 |
| 读取失败或解除关联 | 保留现有会话；音频失败仍由原恢复与安全策略处理 |

保留后台音频、锁屏命令、取消／快速切台、旧异步结果门控、最多两路、静音对两路生效、8 秒切台和 6 秒渐弱。来电、蓝牙／耳机断开、媒体服务重置后的恢复继续要求现有本机确认；配置变化或网络恢复不能改为自动播放。

## 接入默认建议与待确认选择

以下为补齐旧 iPhone 规划的建议，尚不是新增功能已经获选的记录。目录、只读读取和缓存可以先实现；涉及下列产品变化时先沿用当前行为，交付前确认具体选择，不借配置接入修改播放安全策略。

| 选择 | 建议默认 |
|---|---|
| 当前台被隐藏／删除后停止，再次点播放 | 下一次新建连接只面向当前可见且有效的电台；保留失效提示，由用户明确选择，不静默切台 |
| 健康连接使用旧地址，之后发生重连 | 同 ID 仍有效且可见时，下次新建连接采用最新地址；仍受播放意图和安全锁约束；已移除／隐藏台不因重试重新启播 |
| 无缓存且云端不可用时是否提供默认列表收听 | 未关联保留既有默认资料；已关联的空态不冒充同步成功，可另设明确的本机默认资料入口，作为后续单独选择 |
| 解除关联后是否允许清除缓存 | 默认保留；如提供清除，单独确认，只删除 App 私有缓存，不改云端或强制中断当前会话 |
| Apple 账户或提供商身份变化 | 不收集账户标识；可靠的系统变化通知触发来源检查，保留缓存、要求重新授权，不自动归属新来源 |
