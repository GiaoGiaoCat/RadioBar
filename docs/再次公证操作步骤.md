# RadioBar 再次提交 Apple 公证操作步骤

适用于已经在这台 Mac 上成功配置过 `RadioBarNotary` 公证凭据的情况。每次发布新构建都需要提交新的 ZIP；不需要重新创建凭据，除非原凭据已失效或更换了电脑。

## 一、核对新版本文件

1. 将我发来的新 `RadioBar-notary-submission.zip` 放入「下载」文件夹。请确认使用的是**本次新版本的文件**，不要解压或修改 ZIP。
2. 在 Mac 的「终端」执行：

   ```bash
   shasum -a 256 "$HOME/Downloads/RadioBar-notary-submission.zip"
   ```

3. 把显示的 SHA-256 与我这次发送的摘要对照；不一致时先联系我，使用同一份 ZIP 重传。如果文件名或位置不同，请将命令中的路径改为实际位置。

## 二、提交公证

在终端执行：

```bash
xcrun notarytool submit "$HOME/Downloads/RadioBar-notary-submission.zip" --keychain-profile "RadioBarNotary" --wait
```

等待 Apple 处理，记录终端显示的提交编号 `id` 和状态：

- **Accepted**：公证通过，继续获取日志。
- **Invalid** 或 **Rejected**：公证未通过，请获取日志并告诉我。
- **In Progress**：仍在处理中；等待完成后再获取日志。

如果等待中断但已取得提交编号，可以查询状态，避免盲目重复提交：

```bash
xcrun notarytool info "提交编号" --keychain-profile "RadioBarNotary"
```

请将 `提交编号` 换成这一次显示的实际编号。如果提示找不到凭据或凭据失效，请联系我；可能需要在当前 Mac 重新配置 App 专用密码和 `RadioBarNotary` 钥匙串凭据，不要发送你的密码。

## 三、获取日志并反馈

处理完成后，将下面的 `提交编号` 换成这次的实际编号并执行：

```bash
xcrun notarytool log "提交编号" --keychain-profile "RadioBarNotary" "$HOME/Desktop/RadioBar-notary-log.json"
```

请把**公证状态、提交编号、这次 ZIP 的 SHA-256 和桌面上的 `RadioBar-notary-log.json`** 发给我。即使状态为 Accepted，日志也可能包含警告。

之后由我在自己的 Mac 上对原提交包附加公证凭据并生成最终 ZIP；你不需要修改或重新打包文件。不要把 Apple 账户密码、App 专用密码或签名私钥发给我。

参考：[Apple 公证工具说明](https://developer.apple.com/documentation/technotes/tn3147-migrating-to-the-latest-notarization-tool)。
