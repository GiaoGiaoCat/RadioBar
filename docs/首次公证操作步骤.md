# RadioBar 首次 Apple 公证操作步骤

麻烦帮我把签名后的 RadioBar 安装包提交给 Apple 公证。这个流程不需要上架 Mac App Store，也不需要把你的 Apple 账户密码、App 专用密码或签名私钥发给我。

## 一、准备工具和文件

1. 使用联网的 Mac，安装并打开过 Xcode，确保终端可以运行 `xcrun notarytool --version`。如果提示找不到工具，请先安装或设置 Xcode。
2. 将我发给你的 `RadioBar-notary-submission.zip` 放到「下载」文件夹，保持文件名不变。不要解压或修改 ZIP。
3. 在终端执行下面的命令，把显示的 SHA-256 与我发送的摘要对照；不一致时先联系我，使用同一份 ZIP 重传。

   ```bash
   shasum -a 256 "$HOME/Downloads/RadioBar-notary-submission.zip"
   ```

## 二、首次配置公证凭据

首次在这台 Mac 上提交公证时配置。凭据保存后，后续版本通常可继续使用。

1. 登录 [Apple 账户管理页面](https://account.apple.com/)。
2. 在「登录和安全」中找到「App 专用密码」，生成一个新密码，名称可以填 `RadioBar Notary`。账户需要开启双重认证。
3. 打开 Mac 的「终端」，输入下面的命令，把 `你的Apple账户邮箱` 替换为你自己的开发者账户邮箱：

   ```bash
   xcrun notarytool store-credentials "RadioBarNotary" --apple-id "你的Apple账户邮箱" --team-id "8H54LK5X2H"
   ```

4. 终端提示输入密码时，粘贴刚生成的 **App 专用密码**，按回车。输入时不显示字符是正常的。
5. 等待凭据验证并保存成功。密码保存在你自己的钥匙串里，不需要发给我。

这里的团队 ID 是 RadioBar 签名证书显示的团队 ID；如果与你开发者账户里的团队 ID 不一致，请先停下告诉我。具体操作可参考 [Apple 的 App 专用密码说明](https://support.apple.com/zh-cn/102654)。

## 三、提交 ZIP

在终端输入：

```bash
xcrun notarytool submit "$HOME/Downloads/RadioBar-notary-submission.zip" --keychain-profile "RadioBarNotary" --wait
```

等待 Apple 处理。完成后会显示提交编号 `id` 和状态：

- **Accepted**：公证通过。
- **Invalid** 或 **Rejected**：未通过，请把状态和日志发给我。
- **In Progress**：仍在处理中。

如果 ZIP 不在「下载」文件夹，或文件名不同，请将命令中的文件路径改为实际位置。如果等待中断但已取得提交编号，可以用下列命令查询，避免盲目重复提交：

```bash
xcrun notarytool info "提交编号" --keychain-profile "RadioBarNotary"
```

## 四、取得公证日志

将下面的 `提交编号` 换成上一步显示的 `id`，执行：

```bash
xcrun notarytool log "提交编号" --keychain-profile "RadioBarNotary" "$HOME/Desktop/RadioBar-notary-log.json"
```

请把**公证状态、提交编号、ZIP 的 SHA-256 和桌面上的 `RadioBar-notary-log.json`** 发给我。日志要在处理完成后获取；即使状态为 Accepted，日志也可能包含警告。如果未通过，我需要根据日志排查。

之后由我在自己的 Mac 上把公证凭据附加到原 App，并生成最终 ZIP；你不需要修改或重新打包文件。后续每个新构建版本都需要重新提交公证；已保存且仍有效的 `RadioBarNotary` 凭据可以继续使用。

参考：[Apple 公证工具说明](https://developer.apple.com/documentation/technotes/tn3147-migrating-to-the-latest-notarization-tool)。
